# removeEntities

[main]\
open fun [removeEntities](remove-entities.md)(entities: Array&lt;Int&gt;)

Removes a list of entities to the Scene. 

This is equivalent to calling remove in a loop. If any of the specified entities do not exist in the scene, they are skipped.

#### Parameters

main

| | |
|---|---|
| entities | Array containing entities to remove from the scene. |
