# getSource

[main]\
open fun [getSource](get-source.md)(): [String](https://developer.android.com/reference/kotlin/java/lang/String.html)

Returns a view of the material source (.mat which is a JSON-ish file) string, if it has been set. 

Otherwise, it returns a view of an empty string. The lifetime of the string_view is tied to the lifetime of the Material.
