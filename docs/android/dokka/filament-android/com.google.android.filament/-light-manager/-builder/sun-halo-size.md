# sunHaloSize

[main]\
open fun [sunHaloSize](sun-halo-size.md)(haloSize: Float): [LightManager.Builder](index.md)

Defines the halo radius of the sun. 

The radius of the halo is defined as a multiplier of the sun angular radius. Must be at least 1.0.

#### Return

This Builder, for chaining calls.

#### Parameters

main

| | |
|---|---|
| haloSize | radius multiplier. Default is 10.0. |
