# advancedSkinning

[main]\
open fun [advancedSkinning](advanced-skinning.md)(enabled: Boolean): [VertexBuffer.Builder](index.md)

Sets advanced skinning mode. 

Bone data, indices and weights will be set in RenderableManager:Builder:boneIndicesAndWeights methods. Works with or without buffer objects.

#### Return

A reference to this Builder for chaining calls.

#### Parameters

main

| | |
|---|---|
| enabled | If true, enables advanced skinning mode. False by default. |
