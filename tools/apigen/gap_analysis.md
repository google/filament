## 2. Detailed Technical Gap

### `SurfaceOrientation` (`libs/geometry/SurfaceOrientation.h`)

* **Problem**:
  `SurfaceOrientation.java` wraps `geometry::SurfaceOrientation`, which is located in `libs/geometry/` rather than `filament/include/filament/`.

* **C++ Signatures**:
  ```cpp
  class SurfaceOrientation {
  public:
      class Builder {
          Builder& vertexCount(size_t vertexCount) noexcept;
          Builder& normals(const math::float3* normals, size_t stride = 0) noexcept;
          Builder& tangents(const math::float4* tangents, size_t stride = 0) noexcept;
          Builder& uvs(const math::float2* uvs, size_t stride = 0) noexcept;
          Builder& positions(const math::float3* positions, size_t stride = 0) noexcept;
          Builder& triangles(const math::uint3* triangles) noexcept;
          SurfaceOrientation* build();
      };
      void getQuats(math::quatf* out, size_t quatCount, size_t stride = 0) const noexcept;
  };
  ```

* **Missing Capabilities**:
  1. `generate_android.py` currently focuses on `filament/include/filament/`. Supporting `SurfaceOrientation` requires extending APIGen target definitions to include `libs/geometry/include/geometry/SurfaceOrientation.h`.
  2. Stride and array-of-vectors unrolling for builders accepting `float2*`, `float3*`, `float4*`, `uint3*`, and `ushort3*`.

## 3. Out-of-Scope Platform & Carrier Helpers (Handwritten by Design)

Low-level platform integration and OS shims are intentionally excluded from APIGen and maintained by hand:
* **OS Surface Extraction**: `NativeSurface` (extracts `ANativeWindow*` from `Surface`, `SurfaceView`, and `SurfaceTexture` via NDK `<android/native_window_jni.h>`).
* **Platform & Driver Contexts**: `Platform`, `AndroidPlatform`, `AndroidPlatform21` (driver initialization, shared EGL/Vulkan contexts).
* **Carrier & Interop Shims**: `StreamHelper` (HardwareBuffer & SurfaceTexture interop), `PixelBufferDescriptor` (standalone buffer carrier), `SwapChainFlags`, `Filament` (JNI loader), `Entity`, `EntityInstance`, `Asserts`, `MathUtils`, `NioUtils`.
