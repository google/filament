# Filament APIGen

**Filament APIGen** is the automated, zero-cost, compiler-driven language binding generation toolchain for [Filament](https://github.com/google/filament).

It replaces error-prone handwritten JNI C++ bridges and Java wrapper classes with compiler-verified, source-faithful bindings extracted directly from public C++ headers via Clang AST inspection.

---

## 1. High-Level Architecture

APIGen enforces a strict **two-stage split architecture**: front-end extraction is completely decoupled from back-end code emission via a formal JSON Intermediate Representation (IR).

```
 +---------------------------------------------------------+
 |             Filament Public C++ Headers                 |
 |            (filament/include/filament/*.h)              |
 +----------------------------+----------------------------+
                              |
                              v  libclang (AST parsing, SFINAE discovery, Doxygen)
 +---------------------------------------------------------+
 |                 extractor.py (Frontend)                 |
 +----------------------------+----------------------------+
                              |
                              v  JSON IR (conforms to ir_def.ts)
 +---------------------------------------------------------+
 |           Intermediate Representation (IR)              |
 +----------------------------+----------------------------+
                              |
                              v  Python AST emitters (javagen/ package)
 +---------------------------------------------------------+
 |            javagen (Backend Generator & Facade)         |
 +--------------+----------------------------+-------------+
                |                            |
                v                            v
   +-------------------------+  +--------------------------+
   |   Java Wrapper Class    |  |    Zero-Cost JNI C++     |
   |      (*.java)           |  |         (*.cpp)          |
   | com.google.android.     |  | JNIEXPORT with wrapJni   |
   | filament.*              |  | and direct register call |
   +-------------------------+  +--------------------------+
```

1. **Frontend (`extractor.py`)**: Uses `libclang` to parse C++ ASTs, resolve type hierarchies, extract Doxygen documentation into CommonMark, discover SFINAE template traits, and extract declarative `UTILS_APIGEN_*` annotations.
2. **Intermediate Representation (`ir_def.ts`)**: A typed, language-agnostic JSON schema describing classes, methods, fields, constants, enums, templates, and documentation.
3. **Backend Generator (`javagen/` package & `javagen.py`)**: Modular Python package that consumes the JSON IR and emits idiomatic Java classes and zero-overhead JNI C++ bridges.

## 4. Quickstart & Build Commands

### Regenerate All Active Android Targets
```bash
python3 tools/apigen/generate_android.py -j --validate
```
*(Always use `-j` to parallelize across CPU cores. Add `--validate` to run the static parity validator after generation).*

### Statically Validate Java & JNI Bindings
```bash
python3 tools/apigen/verify_bindings.py
```
*(Validates bidirectional symbol parity, JNI signatures, and reflection GetFieldID/GetMethodID descriptors across all Java and C++ files).*

### Run APIGen Unit Tests
```bash
python3 -m unittest discover tools/apigen/tests
```

### Build Desktop Engine (Debug)
```bash
./build.sh -ip desktop debug
```

### Build Android Library & JNI (Debug / Release)
```bash
# Debug
./build.sh -q arm64-v8a -Pip desktop,android debug

# Release
./build.sh -q arm64-v8a -Pip desktop,android release
```
